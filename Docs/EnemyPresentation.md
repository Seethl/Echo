# Перший прохід ворога: реакції та підключення моделі

Сцени, UI, NavMesh і маршрути цього проходу не змінювалися.
EnemyInvestigator лишається єдиним контролером поведінки.

## Що працює без нової моделі

- Перед першою перевіркою почутого шуму ворог зупиняється на
  `heardReactionSeconds` (0.45 с) і повертається до запам'ятованого джерела.
- Часті повтори радіоприманки не запускають цю зупинку знову й знову.
- Під час візуальної підозри ворог повертається до останньої видимої позиції.
- Після погоні швидкість перевірки відновлюється до `patrolSpeed * 1.2`.
- Радіоприманка не відводить ворога з прямої погоні.

## Підключення Animator

EnemyPresentation автоматично додається під час Awake на той самий корінь.
Для постійних налаштувань додайте його вручну на корінь ворога в Edit Mode.
Модель із Animator має бути дочірньою. Рухом керує NavMeshAgent;
використовуйте анімації на місці. За замовчуванням root motion вимикається.

Необов'язкові параметри Animator:

| Ім'я | Тип | Значення |
|---|---|---|
| Speed | Float | Фактична швидкість / chaseSpeed, 0..1 |
| Suspicion | Float | Накопичена візуальна підозра, 0..1 |
| State | Int | Idle=0, Investigating=1, Searching=2, Patrol=3, Suspicious=4, Chasing=5, Returning=6 |
| IsChasing | Bool | Погоня |
| IsSearching | Bool | Локальний пошук |

Імена налаштовуються. Відсутні параметри ігноруються без помилок.
Після зміни імен під час Play викличте RefreshAnimator або переввімкніть компонент.
Controller та кліпи ходи/повороту/погоні потрібно підготувати окремо — цей прохід
не створює готові анімації й не додає модель монстра.

## Записані звуки

В EnemyPresentation можна призначити heardNoiseClip, searchClip, calmClip.
Порожні поля мовчать. Старі suspicionClip, chaseClip і footstepsClip на
EnemyInvestigator зберігають свою поведінку.

footstepVariations — список варіантів кроку. Порожні записи пропускаються,
сусідні різні індекси не повторюються, якщо є вибір. Без кліпів використовується
попередній footstepsClip/тимчасовий звук. Для реальної варіативності призначте
різні файли. Кроки та нові сигнали мають окремі просторові AudioSource.

За замовчуванням кроки задає таймер: walkStepInterval=0.7, chaseStepInterval=0.42.
Коли будуть анімації, додайте EnemyFootstepRelay на об'єкт Animator,
Animation Event `Footstep` у моменти контакту стопи й увімкніть
useAnimationFootsteps на EnemyPresentation. Без цих подій прапорець не вмикати.

UnityEvent onHeardNoise/onSuspicious/onChaseStarted/onSearchStarted/
onReturnedToPatrol дозволяють підключити майбутні візуальні реакції.
Жодного впливу на освітлення, UI чи психоделічні матеріали зараз немає.

## Перевірка

Tools > Echo > Checks > Enemy Behaviour — перевірки в Play Mode на тимчасовому
NavMesh. Запускати у порожній тестовій сцені: наявні активні прогрес та
NavMesh основної гри можуть впливати на результат. Сцени не зберігаються.
У batch mode перевірка сама відкриває порожню сцену тимчасового проєкту,
входить у Play Mode й завершує Unity з кодом результату. Прапорець -quit
не використовувати, бо перехід у Play Mode асинхронний.
Перевіряються реакція, повторні звуки, пріоритет погоні, швидкості, значення
підозри та відсутність обов'язкового Animator/нових аудіокліпів.

Окремо пройти в Play Mode: шум за рогом, повторний шум радіо, поява гравця під
час реакції, втрата гравця за стіною, пауза та поразка. Анімації й сприйняття
записаних звуків оцінювати після призначення реальних кліпів.
