# Меню та ігровий UI

Головне меню використовує власний кадр із кімнати доглядача (Resources/EchoMenuBackdrop.png), темно-синю палітру, світлий текст і золотаві лінії. Пауза, налаштування, повідомлення та панелі читання мають спільний стиль EchoUIStyle. Використано чинний вбудований шрифт із підтримкою української. Системи переходів, часу, курсора, введення й EventSystem збережені.

Постійна стрічка WASD / Ctrl / E / R / F / J / Escape знизу більше не створюється. Допомога доступна через J, контекстна дія — у власній нижній смузі. Ціль показується праворуч угорі та ховається під час модальних взаємодій; індикатори шуму компактніші.

Субтитри радіо мають власну нижню панель із запасом на кілька рядків. Підказки фізичних замка й радіо перенесені вгорі по центру; вони не ділять місце із субтитрами. На паузі й під час читання/завершення зайві ігрові шари приховані. Самі знайдені частоти, код і звукові записи не змінювалися.

Довгі тексти в наявному OpenPanel мають ScrollRect із маскою та прокручуванням коліщатком миші; вони не виходять за межі читальної області. Після повторного відкриття читання починається зверху. Вибір і кнопки панелей збережені.

Змінені спільні файли: GameMenu.cs (побудова меню), InteractionUI.cs (HUD та читання), PropCloseupView.cs (позиція й стиль підказки), MechanicalLockView.cs (прибрано дубль інструкції на 3D-моделі, повідомлення про код надходять через спільний UI). Додано EchoUIStyle.cs та кадр меню з .meta. Сцени, prefab гравця й ворога та ігрові головоломки не перебудовувалися.

Тести й кадри: D:/EchoMergeVerification/QA/ui-play.log та ui-photos. Перевірки виконуються в ізольованій копії Unity; частина сценарію переставляє гравця, ворог вимкнений лише для огляду. Це не повний ручний стелс-прохід чи тест exe.

Ручна перевірка: Stop Play, дочекатися компіляції, Play → меню → налаштування/Назад → Нова гра. Перевірити записку та J, радіо 940 після закриття вікон і фізичний замок, паузу, повтор і повернення в меню. Для довгих текстів — коліщатко миші. Окремо оцінити UI на моніторах команди.

Фон меню плавно затемнюється під кнопками. Статична інструкція на 3D-замку більше не накладається на передачу; при відкритті крупного плану очищаються старі тимчасові повідомлення. Усі дані головоломки та перевірка коду збережені.

Фінальний запуск: 36 перевірок Play Mode errors=False. Реальні розміри Game View — 1280×720 та 1024×768. Перевірені меню/налаштування, записка й прокручування мишею, Escape, пауза, повний субтитр випадкового коду, наведення й клік фізичного замка, відсутність дубльованого world-space тексту, повідомлення неправильного коду, межі панелей, повтор і меню → Нова гра без дублікатів систем.
