# Як протестувати Echo

Відновлений прототип із сімома зонами знаходиться в гілці **romko_main**.
У GitHub Desktop виберіть саме її, потім Fetch origin / Pull. Попередня
версія лише з кімнатою й коридором — старіший коміт у цій самій гілці.

1. Отримайте опублікований коміт через GitHub Desktop або `git pull --ff-only`.
   Спершу збережіть свою незакомічену роботу. Не копіюйте поверх власних змін.
2. Потрібна Unity **6000.6.7f1** і Git LFS для наявних звуків/моделей.
   Якщо LFS-асети не завантажені, виконайте `git lfs pull`.
3. Відкрийте корінь проєкту Echo в Unity Hub. Дочекайтеся імпорту й компіляції.
4. **Play → Нова гра**. Основна сцена — ManorPrototype, усі п'ять сцен включені
   в список для збірки, MainMenu — перша.
5. WASD — рух, миша — огляд, Ctrl — тихі кроки, Shift — біг, E — взаємодія.
   R — радіо, F — живлення, Q — поставити на вільну поверхню, J — журнал,
   Escape — закрити панель або пауза. Лебідка: утримати Space й відпустити
   після подвійного клацання.

Маршрут: доглядач → галерея → хол → бібліотека → кухня → зимовий сад → двір.
У холі радіо на музичному каналі можна залишити в ніші як приманку.
Частоти й критичні підказки є на картках; радіо можна повернути, але втеча
не вимагає нести його до воріт. Після поразки доступна контрольна точка.
Продовження працює лише в межах поточного запуску, без збереження на диск.

Документація компонентів і маршруту: [ManorPrototype.md](ManorPrototype.md).

## Що вже запущено

- Геометрія: 26 перевірок; FPS фізично пройшов сім зон, сарай і вихід.
- Головоломки без ворога: 81 перевірка, повний цикл до завершення.
- Радіо й просторовий звук: 100 перевірок разом із повторним проходженням.
- Окремі сценарії ворога й відновлення: 32 перевірки.
- Спільний сценарій з активним ворогом і приманкою: **127 перевірок, без
  помилок виконання** в Unity 6000.6.7f1 у тестовій копії.

Автоматичні тести позиціонували гравця біля предметів для точних перевірок;
це не повне ручне проходження від старту. Рух до виходу та перевірку геометрії
виконано FPS-керуванням. Окрему збірку, комфорт гри, баланс ворога та звучання
на різних комп'ютерах команда має перевірити вручну.

Після перенесення файлів також запущено основний проєкт: Play → меню →
Нова гра → кімната доглядача ManorPrototype. Під час цієї перевірки запуск
не спричинив падіння. Це не гарантія відсутності помилок на інших машинах.

Моделі й частина звуків тимчасові. Голоси замінені сигналами й субтитрами;
AudioClip можна призначити на каналах без зміни логіки. Перший запуск може
ненадовго затриматися через побудову навігації.
