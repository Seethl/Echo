# Прогресія та звукове прикриття

Окрема сцена: `Assets/Scenes/Testing/PlayerTest/SoundProgressionTest.unity`.
Локація й UI друга не змінені. Звичайний Play запускає відкриту сцену.
Якщо вручну ввімкнули `Echo → Починати Play з головного меню`, вимкніть
цю опцію для локальної перевірки.

## Перевірка

1. Play: можна бігати поруч з істотою — вона не чує й не ловить.
2. F6: істота починає перевіряти звуки, але контакт ще безпечний.
3. F9: чотири секунди дзвону. Кроки чутно гравцю як раніше, але радіус
   їх виявлення зменшується вчетверо. Приклад: ходьба по дереву 6 → 1,5 м;
   біг 12 → 3 м. Тому навіть під дзвін не можна безпечно бігти біля істоти.
4. Після завершення дзвону звичайна чутність повертається автоматично.
5. F7: контакт стає небезпечним; спіймання та R працюють як раніше.
6. F8: етап SoundMastery. Це лише сигнал розблокування для наступної механіки;
   переносний будильник поки не реалізований.

Пауза зупиняє час дзвону та блокує тестові клавіші. Для повтору вступного
етапу перезапустити сцену: прогресія просувається лише вперед.

## Інтеграція з головоломками

`GameProgression` зберігається в сцені, не в глобальному singleton чи PlayerPrefs.
На істоті додати `EnemyThreat`, призначити посилання `progression`.
Без EnemyThreat старі тести зберігають попередню поведінку; з компонентом,
але без посилання істота залишається безпечною.

Із подій завершення головоломок викликати `Awaken()`, `RaiseDanger()` та
`UnlockSoundTool()`. Повторні або старі події не знижують етап і не дублюють
`onStageChanged`. Час сам по собі небезпеку не підвищує.

`NoiseMaskingSource` додати до об'єкта з AudioSource (годинник, радіо, гроза).
`PlayCover()` запускає призначений кліп. Тривалість кліпу визначає вікно
прикриття; loop дозволено тільки для постійного фонового джерела.
Для локального прикриття і джерело кроку, і слухач мають бути в межах radius.
Перетини зон використовують найсильніше прикриття, а не перемножуються.
Зупинений, вимкнений або muted AudioSource не створює прикриття.
Параметри загальної гучності гравця не змінюють баланс AI.

Дзвін у тестовій сцені синтезований лише для перевірки. Прикриття не є
приманкою: воно не створює подій шуму й не перенаправляє істоту.
