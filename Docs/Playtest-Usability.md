# Повторний тест без підказування відповідей

Відкрити проєкт у його поточній версії Unity. Play → Нова гра.
Не використовувати попередню карту з відповідями. Розробник не пояснює рішення.

Керування: WASD, миша, Ctrl — присідання, E — предмет під крапкою.
Радіо: R — панель, F — живлення, Q — поставити на вільну поверхню.
J — знайдені записи й допомога на запит. Escape — закрити панель / пауза.

1. Пройти службові кімнати та знайти вхід у хол.
2. З безпечного місця роздивитися хол, знайти наступну зону й місце для приманки.
3. У бібліотеці без пояснення розробника визначити, що можна слухати,
   де вводити порядок, як скинути його й що саме відкривається.
   Навмисно ввести одну невдалу повну комбінацію, потім повторити спробу.
4. Знайти потрібний кухонний предмет, зрозуміти дію лебідки.
   Один раз відпустити кнопку зарано; відійти та повернутися до роботи.
5. У саду знайти інструмент і зрозуміти, коли навколишній шум допомагає.
6. У дворі знайти інструменти й вийти з території.
   Спершу оглянути стан стулки й ланцюга. Спробувати перервати тривалу дію,
   сховатися й продовжити, не втрачаючи завершеного прогресу.
7. Перевірити поразку / повернення від точки, головне меню, нову гру.
   Нова гра повинна очистити всі предмети та механізми попереднього запуску.

На різних поверхнях пройти звичайним кроком, присісти та пробігтися:
чи відповідає «Твій шум» очікуванню? Поставити радіо й відійти: воно не має
залишатися власним джерелом на смузі. Підійти до фонового джерела та відійти:
чи зрозуміло, чому змінюється «Шум оточення»? Повторити із вимкненим Master Volume.

Якщо застрягли на 60–90 с, спершу відкрити J, потім допомогу по одному кроку.
Нехай тестувальник сам вирішує, чи потрібен наступний рівень допомоги.

Для кожної затримки записати:

| Де / що бачив | Чого очікував від предмета | Що натиснув / що сталося | Якої підказки не помітив | Що допомогло |
|---|---|---|---|---|
| | | | | |

Окремо відмітити: чи дав ворог час зрозуміти бібліотеку, чи лишився шлях відступу,
чи читалися символи та таблички на вашій роздільній здатності. Не оцінювати
красу тимчасових моделей — нас цікавлять правила й зрозумілі дії.
