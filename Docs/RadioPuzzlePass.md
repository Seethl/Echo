# Радіо, звукові асоціації та фінал біля воріт

Цей прохід доповнює збережені зміни UsabilityPass. Основна сцена й усі попередні
локальні зміни залишені в поточній гілці; сцена не генерувалася заново.

## Відповіді поточного запуску

ManorProgress створює один тризначний код і один порядок трьох бібліотечних
символів. RunSecrets зберігає їхні ідентифікатори в наявному словнику прогресу.
Нова гра / повний повтор дає інші відповіді, ніж попередня гра цього запуску.
Контрольна точка, поразка та Continue зберігають ті самі відповіді.
Збереження на диск не додавалося.

- KeypadLock.Use Run Code вмикає код запуску. В інших тестових сценах старий
  параметр Code зберігає свою поведінку.
- SymbolPuzzle.Use Run Order вмикає порядок запуску; старий Solution лишається
  налаштуванням для сцен без цього прапорця.
- Gallery940.Payload = GalleryCode; шаблон Transcript містить `{code}`.
  До закривання віконниці звучить/показується лише обірваний текст без цифр.
- Library1060.Payload = LibrarySounds; `{sounds}` підставляє описи реальних звуків
  у порядку поточної гри. Записки дають частоти та правила, а не відповіді.

Радіо тепер є джерелом змінних відповідей. Почутий поруч запис доступний у J,
тому його не треба тримати ввімкненим для повторного читання. Залишене далеко
радіо не дописує журнал і не ставить прапорець recording.heard дистанційно.
Забуте радіо можна забрати зі стартової кімнати чи місця, де його залишили.
Початкова записка про ключ збережена як навчальна допомога.

## Асоціативні звуки

Панелі та відповідні символи зберігають свої позиції й оформлення:

- Місяць: низький нічний передзвін із довгим відлунням.
- Дерево: сухий скрип і два глухі удари.
- Птах: два високі посвисти.

Це тимчасові синтезовані AudioClip, але радіо справді відтворює ті самі
аудіофрагменти в змінному порядку з паузами, а не один загальний сигнал.
Субтитри описують тембр, а не називають потрібні кнопки. Демонстрації та радіо
не накладаються; повну передачу можна повторити кнопкою в R.

На SymbolButton налаштовуються Use Association Sound, Sound Cue і Rhythm
(опис для субтитрів). Для заміни тимчасового звуку задайте Rhythm Clip на
демонстраційній панелі. Радиопослідовність використовує цей самий кліп;
для читання семплів потрібен Import Setting: Decompress On Load. Після заміни
кліпів перезапустіть Play. AudioClip полів Voice Clip на поточних записах немає.

## Ворота

Стулка навантажує ланцюг. Перед різанням треба підперти її вже отриманим ломом
у позначеному місці біля правої петлі. Болторіз залишається в доступному сараї;
нових ключів і випадкових пошуків не додано.

Після підпори кожна із двох секцій ріжеться утриманням E протягом 3 секунд.
Потрібно залишатися в межах взаємодії та дивитися на ланцюг; рух і огляд доступні.
Відпускання E, відхід, втрата прицілу або пауза скасовують лише поточний
незавершений зріз. Готові секції та підпора зберігаються в контрольній точці.
Для другої секції потрібно відпустити й знову затиснути E.

Робота створює дискретні скрипи, завершення секції — сильний звук. Мешканець
реагує через чинний NoiseSystem; його ніхто не телепортує до воріт. Додане
укриття збоку від підходу дає місце для відступу. Радіоприманка лишається
доступною тактикою; після відкриття воріт забирати радіо не потрібно.

ToolBarrier.Hold Seconds = 0 зберігає старе одноразове натискання (сад).
На ланцюгу Hold Seconds = 3, Required Flag = gates.braced. FlagInteraction
підпори перевіряє Required Key Id = tool.crowbar і показує Completed Visual.
Додаткових менеджерів, систем введення чи курсора немає.

## Серіалізація патруля

Виявлено помилку попереднього форматування YAML: порожні рядки в
patrolUnlockFlags були записані як окремий `-`, і Unity читала весь список
порожнім. Умови доступу бібліотеки, кухні, саду та двору відновлено; порожні
рядки записані явно як `- ""`. Перевірки виконуються після повторного
завантаження саме цього файлу сцени.

## Файли та інтеграція

Додано RunSecrets.cs і ManorRadioPuzzleUpgrade.cs з новими .meta. Змінено
ManorProgress, KeypadLock, SymbolPuzzle/Button, RadioChannel/PortableRadio,
PrototypeAudio, ToolBarrier, FlagInteraction, MechanismReadout, виклик у
ManorPrototypeBuilder, основну сцену та два наявні RadioData assets.
Оригінальні GUID, попередні зміни геометрії, меню, тестові сцени, швидкості,
радіуси слуху та зору збережено. Unity, пакети й ProjectSettings не оновлювалися.

Зір мешканця має перевірку перешкод. Сильний звук за стіною може привернути
увагу, а після втрати видимості він перевіряє останнє відоме місце — це окремо
від безпосереднього зорового контакту. Не слід прибирати слух за стіною разом
із перевіркою зору.

## Повторний тест без відповідей

1. Почати нову гру, прочитати картку галереї. Перевірити, чи зрозуміло,
   навіщо повернутися по радіо, якщо його не взяли.
2. Усунути гуркіт і отримати поточний код саме через передачу.
3. У бібліотеці порівняти характер звуків панелей із записом. Відзначити,
   який звук важко впізнати та чи допомогли субтитри, не підказуючи назву кнопки.
4. У дворі оглянути ворота, підготувати стулку й вибрати момент для різання.
   Перервати один зріз, потім виконати секцію, відійти та продовжити.
5. Повернутися в меню й натиснути Continue: відповіді, підпора та готовий зріз
   повинні зберегтися. Нова гра повинна очистити прогрес і змінити відповіді.
6. Сховатися за непрозорою стіною або стелажем: відзначити, чи мешканець
   безпосередньо бачить гравця, чи йде перевіряти попередній шум/позицію.

Для кожної затримки записати місце, очікувану дію, фактичну реакцію та
непомічену підказку. Звуковий мікс і темп переслідування оцінюються вручну.

## Фактичні перевірки

Unity 6000.6.7f1, ізольована копія з тими самими локально кешованими URP,
InputSystem і UGUI; основні пакети не змінювалися. Фінальний запуск завантажив
вже впорядкований файл сцени з явними порожніми рядками патруля.
RADIO_RESULT: checks=223; errors=False.

Перевірено справжніми натисканнями UI та клавіш: меню, налаштування/повтор радіо,
обірвану й повну передачу, випадковий код на коліщатках замка, відсутність
відповідей у картках, бібліотечні панелі, завершений ввід і скидання, отримання
руків'я, лебідку, сад, підпору, тривале різання, переривання й паузу. Повернення
в меню та Continue після першої секції зберегло підпору, зріз і обидві відповіді;
повний повтор дав інші відповіді та чистий стан. Окремо перевірено, що віддалене
радіо не заповнює журнал, і семпли переданих звуків збігаються з локальними
панелями у правильному порядку.

FPS із незміненою швидкістю фізично пройшов основний маршрут після відкриття
перешкод і завершив гру. Під час ланцюга головоломок ворог відключений;
патруль, слух, приманка, переслідування, поразка й відновлення перевірені окремо.
Зір перевірено на реальній стіні кухні, стелажі бібліотеки й зачинених дверях;
відкриття тих самих дверей дозволяє побачити гравця. До окремих взаємодій
автотест програмно переміщує гравця. Це не безперервне людське стелс-проходження.

Графічний рендер вимкнений. Слід вручну послухати впізнаваність трьох тимчасових
тембрів, оцінити гучність міксу, читабельність підпори та темп небезпеки біля воріт.
