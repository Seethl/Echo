ОСТАННІЙ УПРАВИТЕЛЬ / THE LAST STEWARD

Авторська low-poly модель монстра для старого маєтку.
1005 вершин, 1737 трикутників, 63 окремі деталі. Висота близько 2.76 м.
Координати: Z вгору, обличчя в напрямку -Y. Масштаб у метрах.

Швидке відкриття: Blender > File > Import > Wavefront (.obj),
обрати last_steward.obj. Файл last_steward.mtl має лежати поруч.
Для правильної орієнтації: Forward -Y, Up Z.

Сцена з камерою та світлом (Blender 4.x/5.x):
1. Scripting > Open > обрати open_in_blender.py.
2. Run Script (Alt+P).
3. Скрипт створить окрему сцену та збереже last_steward.blend
   і last_steward_preview.png у цій папці.
Збережіть поточну роботу перед запуском: скрипт зберігає весь відкритий
файл Blender під новим іменем, включно з іншими його сценами.

Модель без скелета, анімацій, UV-розгортки та текстурних зображень.
Кольори задані матеріалами. Поза статична. Пласкі грані навмисні.
Модель не є замкнутою сіткою для 3D-друку.
Blender у середовищі створення недоступний: скрипт сцени не виконувався.

generate.cjs — процедурне джерело геометрії; запускається Node.js.
