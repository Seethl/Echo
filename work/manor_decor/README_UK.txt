18 ПРЕДМЕТІВ ДЕКОРУ ДЛЯ МАЄТКУ

Unity: Assets/Props/ManorDecor. Перетягуй PF_Decor* у сцену.
Масштаб у метрах, origin кожного предмета по центру біля основи.
Став Y на висоту столу, полиці або підлоги.

DecorBook — одна книга; DecorBookStack — стопка; DecorBookRow — ряд книг.
DecorCrate — дерев'яний ящик; DecorParcel — картонна коробка.
DecorSuitcase — валіза; DecorBottle — пляшка; DecorJar — банка.
DecorMug — чашка; DecorPlate — тарілка; DecorKettle — чайник.
DecorVase — ваза; DecorCandle — свічка на свічнику (без полум'я/світла).
DecorNote — записка; DecorPortrait — стилізований портрет у рамі.
DecorRolledRug — згорнутий килим; DecorCoveredObject — накритий предмет.
DecorBucket — відро.

Статичний декор: немає відкривання, підбирання, фізики тканини чи Rigidbody.
Кожний prefab має простий BoxCollider за габаритами. Він також займає
порожнину чашки/вази/відра — для точної фізики потрібні інші колайдери.
Записка містить декоративні рядки без читабельного тексту.
Портрет зроблений пласкими простими формами, без сторонніх зображень.
Скло пляшки й банки непрозоре, для стилю low-poly.

Матеріали URP спільні для набору. Дерево використовує старий атлас,
решта поверхонь — кольорові матеріали. UV дерева вже налаштовані.
DecorManifest.json містить розміри та кількість трикутників предметів.

Blender: ManorDecor_Library.blend — всі 18 предметів на сітці, окремі mesh.
Текстура дерева запакована. FBX експортовані окремо з origin в нулі.
build_decor.py — генератор; Tools > Echo > Build Manor Decor — prefab builder.
