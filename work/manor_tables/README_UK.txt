ДВА СТОЛИ ДЛЯ СТАРОГО МАЄТКУ

Unity: Assets/Props/ManorTables
PF_ManorDesk — письмовий стіл із двома тумбами, 1.60x0.76x0.78 м.
PF_ManorTable — простий стіл із поперечинами, 1.80x0.85x0.78 м.
Готові URP матеріали, UV, складені BoxCollider; корінь у центрі на підлозі.
Перетягни prefab у сцену, постав Y на висоту підлоги.
Колайдери не закривають весь об'єм під столом одним великим блоком.

2288 трикутників для письмового; 704 для простого.
Фасади шухляд і дверцят тумб статичні, без анімацій та взаємодії.
Письмовий стіл має два матеріали: дерево й латунь; простий — дерево.
Текстура дерева спільна, повторно використана з атласу дверей маєтку;
UV розміщені на ділянці дерева всередині першої фільонки атласу.
Текстурою покриті всі сторони, включно зі зворотними.

ManorDesk.blend та ManorTable.blend — окремі вихідники Blender,
текстура запакована всередині. У Blender вісь висоти — Z, в Unity — Y.
build_tables.py — генератор. Повторна збірка prefab у Unity:
Tools > Echo > Build Manor Tables.
